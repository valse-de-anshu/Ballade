# QuickShell Ballade Custom Sounds

Place any custom audio files (`.flac`, `.wav`, `.mp3`, `.ogg`, `.oga`, `.opus`, `.m4a`) here to easily select them in the **Settings Hub (`Super + I`) -> Services -> Notifications & Audio**.

Recommended event sound names:
- `notification.flac` / `notification.wav`
- `alarm.flac` / `alarm.wav`
- `pomodoro.flac` / `pomodoro.wav`
- `shutdown.flac`
- `lock.flac`
- `charger-plugged.flac`
- `charger-unplugged.flac`
- `battery-full.flac`
- `usb-in.flac`
- `usb-out.flac`
